## What exists now that did not this morning

1. **The tab/session model** (`stage-e-console::tabs`): a tab is a **host-run TINYCMD session
   in-process** — `shell::verbs::World` + `shell::dos::run_line`, the same crate the QEMU
   fixture boots. Fixed enumeration of six tab identities (`tab-1`…`tab-6` /
   `TAB-1`…`TAB-6`); every refusal typed (capacity, unknown label, wrong kind); per-tab
   env/cwd/volume/policy isolation proven headless (`t1`–`t7`) and through the real IPC path
   on MockRuntime (`e6`).
2. **The window shape — `a3` made visible**: one `host` window; sibling webviews `reserved`
   (host-owned strip), `console` (tab-bar chrome) and the tab contents. A Rust-side
   reconciler composes the window from registry state and is the *only* writer the reserved
   region has; the reserved label is enumerated nowhere in the manifest, so it holds no verbs
   (`r6`, `e8`) — "no tab content can paint it" is a grant-table property, not page
   discipline.
3. **The signed manifest grew per-identity grant tables** (`m5`): chrome verbs
   (`launch_fixture`, `send_line`, `read_stream`, `terminate`, `open_tab`, `focus_tab`,
   `read_console`) vs tab verbs (`run_line`, `read_tab`, `run_parity`), disjoint by intent —
   a tab cannot open tabs, the chrome cannot run lines, and both refusals are visible in the
   UI (`r5`, `e7`, screenshot 07). A tab verb's session identity is the invoking webview's
   runtime-derived label; there is no argument through which another tab's session can be
   named. Re-signed with `sign-manifest`; the dev-key non-claim stands.
4. **The parity suite runs from a tab** (`stage-e-console::parity_suite`): one button, the
   two CI command surfaces, live-streamed per-test PASS/FAIL rows, the two signals rendered
   separately, the aggregate in the reserved region. Parsers and the two-signal aggregation
   are pure and host-tested (`s1`–`s3`).
5. **`SAMPLE.TCB` — a batch file delivering on expectations, visibly** (owner's ask): every
   DOS tab's volume seeds a sample `.TCB`; typing its name at the prompt runs it through the
   real `.TCB` runner (echo discipline, `%VAR%` expansion, volume writes), on-screen
   (screenshot 05), and its side effects stay inside that tab's session (`t7`).
6. **Two small `shell` additions, test-first**: `World.policy` is now `&(dyn VerbPolicy +
   Sync)` so a host tab owner can hold a `World<'static>` behind shared state
   (`c5_world_static_is_send`, red-first as a compile failure), and the batch prompt renderer
   is public (`b4`) so interactive echo is byte-identical to `.TCB` echo. Shell host tests
   **22/22** (were 20).

## Findings worth carrying

1. **The smoke must be label-independent.** The first smoke run found a fourth tab already
   open at boot — a stray click on the live desktop had activated the focused "+ DOS tab"
   button — and the sequence, then hard-coded to `tab-3`, drove the wrong tab. The sequence
   now reads the registry for the first two DOS tabs and the parity tab (17G says *≥3 tabs*),
   and records the role→label mapping in the JSON. Unattended-on-a-live-desktop is a real
   test condition; index assumptions are not.
2. **`cargo test -p tauri --lib` with default features dies at load on this box**
   (`STATUS_ENTRYPOINT_NOT_FOUND`) because default features include `common-controls-v6` —
   the same comctl32-v6 manifest fact REPORT-2026-07-29-04 finding 3 recorded for the app.
   The knob suite is the headless one: `--no-default-features --features test[,tinyos]`.
3. **Cross-workspace path dependency `tinyos-poc → os/src/shell` works and is direction-legal**
   (the `external/` exclusion rule forbids only the reverse; `check-external-isolation` still
   green). The shell crate's workspace-inherited fields resolve against `os/`'s workspace
   root even when built from the PoC workspace.
4. **Stated debt, deliberately:** the window is fixed-size (no resize-following layout);
   unfocused tabs are hidden webviews, not suspended sessions; one parity-suite state means
   one parity tab is meaningful at a time; the suite runner shells out to `cargo` and parses
   its human-readable output (the same surface CI reads, but a format change would surface as
   a red row, which is the safe direction). None of these blocks the mandate; none is hidden.
