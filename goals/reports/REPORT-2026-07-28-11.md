## Raw evidence

### Clause 1 — generated, and the generator is the fix

`emit-dashboard` prints the block; `check-assurance-spine` byte-compares the committed region against it and, on mismatch, prints the expected block. The command deliberately **does not** run the dashboard check — a command whose job is to print the repair for a stale page must not require the page to be fresh — and deliberately does not write the file, so applying it is a reviewable diff.

### Clause 3 — the gate demonstrated against a live cross-session dependency

While this Story was being verified, a concurrent session had `LE-47` in its working tree, uncommitted. The dashboard gate refused the tree with:

```text
goals/index.html does not state the current loose-end counts.
Expected `<strong>47 loose ends (29 open)</strong>` (LE-30)
```

That is the check working, not a defect: a register row and the page summarising it had gone out of step, and previously nothing would have said so. This session's own subset was verified over clean `HEAD` in a throwaway worktree — the response [`agent/CONCURRENT_SESSIONS.md`](../../agent/CONCURRENT_SESSIONS.md) rule 8 prescribes — and passed.
