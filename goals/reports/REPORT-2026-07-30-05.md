## What this report claims

1. **WP0's software half is frozen.** `ADR 0011` adopts `LAT-PHYS-10` (strict
   `< 10,000 ns`, `t_apply_last − t_sample_first`) and its sibling vocabulary as
   non-substitutable, freezes the event/endpoint contract as the one-page diagram,
   rejects the two-event 100 Mbit/s EtherCAT architecture for strict `LAT-PHYS-10`
   from serialization physics alone (2 × 6.72 µs = 13.44 µs > 10 µs before any
   software cost), and adopts Option B (FPGA/edge closed loop) as the leading test
   architecture with the §5 gate held **open** pending named hardware.
2. **The `R4` contract gap is closed in code.** The `motion` crate's feedback
   identity is now a closed ownership sum — axis-owned, end-effector-owned,
   group/process-owned — declared per channel in the profile and enforced by
   whole-epoch validation. The `Auxiliary` dumping ground is gone. The forbidden
   cast (probe data presented as axis feedback) is a driven positive control that
   rejects the whole epoch.
3. **The Hexapod sensor set validates as one epoch.** Three axes with motor- and
   load-side channels, one probe-deflection channel, one group metrology channel:
   accepted whole when complete; rejected whole when the probe bit is missing or
   stale — the probe is load-bearing coupled feedback, not an optional extra.
4. **TDD held.** The suite was rewritten/extended first and observed failing as a
   43-error compile-stage Red; Green with 61 tests (51-test `-01` shape retained
   without weakening) and no test edited afterward.
5. **The measurement protocol has a dated template.**
   [`_lat-phys-10-report-template.md`](_lat-phys-10-report-template.md) implements
   §10/§11 verbatim, including the mandatory positive controls (injected known
   delay, clock-skew corruption) without which a run is inadmissible.
