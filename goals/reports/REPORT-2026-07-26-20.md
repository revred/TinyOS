**Deliberately not done:**

- **No execution of the image's own entry point.** `blue-sharc.exe` imports 220 Win32/CRT functions across 14 DLLs (sockets, TLS, crypto, C++ exception unwinding, full CRT init) — its own C runtime calls dozens of these before `main` even runs. This kernel has no per-task `CR3` switch, no IDT/interrupt/exception-handling subsystem, and no threads. Implementing that surface is several more Features' worth of work, recorded as this Story's own natural next step, not attempted here. See `STORY-P0-05-04.md`'s own correction note.
- **No production call site.** `kernel`'s own binary still doesn't link `exec` — unchanged from `STORY-P0-06-03`/`-04`'s identical "no dispatcher wired into `main.rs`" gap.
- **No TXE security scanning/signing/sandboxing.** Recorded in `goals/epics/backlog.md` under `EPIC-P5`, per a 2026-07-26 direction — needs the real `aci` engine, not built yet.
